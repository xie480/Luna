## 2. 字段级补充（逐接口 + 字段类型）

> 本节补齐“每个接口”的字段级类型说明。  
> 说明：
> - `?` 表示可选字段；
> - 别名接口与主接口结构一致时复用同一结构；
> - `object/map` 表示动态对象（键不固定，由业务返回）。

### 2.1 登录 / Chat / SSE / 审批：接口-类型映射

| 接口 | 职责 | 入参字段与类型 | 回参字段与类型 |
|---|---|---|---|
| `POST /auth/login` | 登录签发 token | `LoginRequest` | `LoginResponse` / `AuthError` |
| `POST /auth/logout` | 登出并拉黑当前 token | 无 body（Header: `Authorization:string`） | `MessageResponse` |
| `POST /luna/api/chat/message` | 对话主入口 | `ChatRequest` | `ChatDynamicResponse` / `ContextGovernanceBlocked` / `"empty input"` |
| `POST /luna/api/chat/startup` | 启动欢迎与恢复 | 无 body | `ChatDynamicResponse` / `ContextGovernanceBlocked` |
| `POST /luna/api/chat/shutdown` | 记录关机事件 | 无 body | HTTP 200 空 body |
| `GET /luna/api/chat/history/date` | 查某年月历史日期 | query: `ym:string` | `string[]`（`["09","10"]`） |
| `GET /luna/api/chat/history` | 查某日历史消息 | query: `ymd:string` | `string[]`（`ROLE:content:time`） |
| `GET /api/luna/status/stream` | 建立 SSE 长连接 | 无 | SSE 事件流（见 2.7） |
| `GET /api/luna/status/disconnect` | 主动断开 SSE | 无 | `string`（纯文本） |
| `POST /mcp/tools/approval` | 提交审批结果 | `ApprovalSubmitRequest` | `ApprovalSubmitResponse` |
| `POST /mcp/skills/approval` | 审批兼容别名（条件开启） | `ApprovalSubmitRequest` | `ApprovalSubmitResponse` |
