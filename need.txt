Resource 实体类（必须生成）

class Resource {

String type; // tool / skill
String name;
String description;
String version;
String owner;
String inputSchema;   // JSON string
String outputSchema;
String endpoint;
String runMode;       // sync / async

}

2. Agent Orchestrator（核心）

实现完整调用流程：

步骤：

调用 MCP 获取候选 tools/skills

调用 LLM（决策阶段）

调用 LLM（参数阶段）

JSON Schema 校验

校验失败 → 自动修复（再调用 LLM）

通过 Execution Gate（权限/审批模拟）

调用 Tool 或 Skill

返回结果
